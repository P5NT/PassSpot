# Pass Spot

**A premium event discovery, ticketing, and event management platform for the Nigerian market.**

Pass Spot is a frontend-only prototype built with HTML, CSS, and vanilla JavaScript. It demonstrates a realistic commercial event platform — including event discovery, ticketing, wallet, payments, withdrawals, advertising, and an admin interface — with a cohesive design system.

## ⚠️ Important — Frontend Prototype Only

This project contains **no backend**. All "financial" and "authentication" actions are simulated for demonstration. **No real money is transferred. No real accounts are created.** Never enter real financial credentials.

## Features

- Event discovery with full filtering (36 states + FCT, categories, price)
- Event creation with Nigerian location cascade
- Digital tickets with QR placeholder
- Wallet with balance, deposit, withdrawal simulations
- Multi-currency display (₦ NGN / $ USD) with a mock rate
- Advertisement campaign creation and dashboard
- Payments history, transaction detail
- Notifications, favorites (persisted), profile, settings
- Admin interface for users, events, withdrawals, ads, audit logs
- Light / dark theme
- Fully responsive
- Accessible: semantic HTML, ARIA, keyboard navigation

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (no frameworks)
- localStorage for UI state persistence (safe, non-sensitive data only)
